# STEP 3 — Create configmap.yaml

Create file:

```text
helm-train1/templates/configmap.yaml
```

Put this:

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ .Values.APP_NAME }}-config
data:
  application-dev.yml: |
{{ .Files.Get "config/application-dev.yml" | indent 4 }}
```

# STEP 4 — Modify deployment.yaml

Now open:

```text
helm-train1/templates/deployment.yaml
```

---

## ADD volumeMounts

Inside:

```yaml
containers:
  - name: ...
```

add:

```yaml
volumeMounts:
  - name: app-config
    mountPath: /etc/config
```

Place it near:

* ports
* env
* resources

same level indentation.

---

# STEP 5 — ADD volumes

At POD SPEC LEVEL.

Near bottom of deployment:

```yaml
spec:
  template:
    spec:
```

add:

```yaml
volumes:
  - name: app-config
    configMap:
      name: {{ .Values.APP_NAME }}-config
```

IMPORTANT:
`volumes` is NOT inside container.

It is inside pod spec.
